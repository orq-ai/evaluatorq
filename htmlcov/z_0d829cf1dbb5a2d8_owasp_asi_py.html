1"""OWASP ASI (Agentic Security Initiative) attack strategies. 

2 

3These strategies are designed to be AGENT-CONTEXT-AWARE - they use placeholders 

4like {tool_name}, {agent_description}, {memory_store} that get filled with 

5actual agent capabilities at runtime. 

6 

7Only categories with evaluators are fully implemented: 

8- ASI01: Agent Goal Hijacking 

9- ASI02: Tool Misuse & Exploitation 

10- ASI05: Unexpected Code Execution 

11- ASI06: Memory & Context Poisoning 

12- ASI09: Human-Agent Trust Exploitation 

13 

14Note: Generic single-turn attacks are in the static dataset. These dynamic 

15strategies specifically target agent capabilities (tools, memory, context). 

16"""
