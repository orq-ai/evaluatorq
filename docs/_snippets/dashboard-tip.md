!!! tip "View results in the local dashboard"
    Browse saved runs with the multi-run FastHTML dashboard via `eq dashboard`
    (no path browses both stores; `eq dashboard .evaluatorq/sim-runs` scopes to
    simulation). Passing a single JSON report is an optional direct deep-link.
    The legacy `eq redteam ui` / `eq sim ui` Streamlit views remain callable but
    are deprecated.
